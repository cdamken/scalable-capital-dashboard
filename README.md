# 📊 Scalable Capital Dashboard

Local, private, and fast dashboard to visualize your **Scalable Capital**
portfolio — both **Scalable Broker** (self-directed ETF brokerage) and
**Scalable Wealth** (roboadvisor) in one view.

Powered by [`sc-api`](../sc-api/) (sibling repo).

## Status

🚧 **Early development.** Waiting on `sc-api` to be usable. See
[CLAUDE.md](CLAUDE.md) for the design contract.
